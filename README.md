> ### ЕСЛИ АНТИВИРУС РЕАГИРУЕТ НА WinDivert
> WinDivert способен вызвать срабатывание антивируса.  
> Это средство перехвата и фильтрации сетевого трафика, которое требуется для работы zapret.
> Один и тот же инструмент могут применять и безопасные, и вредоносные программы, однако сам WinDivert вирусом не является.
>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует файлы WinDivert как потенциально опасные либо как инструменты для взлома. В результате файл может быть удалён и отправлен в карантин. Как правило, такое обнаружение обозначается именем `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте папку с zapret в список исключений антивируса либо отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, лучше добавить папку в исключения. При отсутствии такого понимания рекомендуется отключить обнаружение PUA.

## ⚙️Настройка и запуск

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS, выбрав любой вариант, кроме "Поставщик по умолчанию"
    * В Firefox откройте настройку "DNS через HTTPS", выберите режим "Персональный", затем нажмите "Выбрать провайдера/поставщика" и вручную укажите URL. Например, подойдёт `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах системы — [инструкция находится здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот способ рекомендуется
    * Владельцам роутеров Keenetic нужно включить в настройках устройства параметр "Транзит запросов". Если его отключить, при настройке и работе Secure DNS на компьютере могут возникнуть проблемы

2. Загрузите zip- или rar-архив со [страницы последнего релиза](https://github.com/portalchemistagitate/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов

5. Запустите необходимый скрипт
    * Чтобы найти подходящую стратегию, откройте **`service.bat`** и последовательно выберите `Run Tests` -> `Standard tests` -> `All configs`
    * Для включения автоматического запуска используйте **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Назначение файлов и пунктов меню

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества факторов, поэтому **перебирайте стратегии (ALT, FAKE и другие), пока не найдёте подходящую именно для вашей системы**

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск через services.msc</ins>
  - **`Remove Services`** — удаляет стратегию и WinDivert из служб
  - **`Check Status`** — показывает состояние обхода и служб, включая стратегию в автозапуске и WinDivert
  - **`Game Filter`** — включает или отключает отдельный режим обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию необходимо перезапустить.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — меняет режим обработки сервисов, перечисленных в `ipset-all.txt`.  
  Этот пункт пригодится при проверке ресурса, который без zapret открывается, а с ним перестаёт работать.  
  В скобках показывается выбранный режим:
    - `none` — ни один IP не проверяется
    - `loaded` — проверяются IP из списка
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включает или выключает автоматический поиск обновлений
  - **`Replace active fakes`** — заменяет текущий используемый fake на другой файл из каталога `bin`
  - **`Update IPSet List`** — загружает свежую версию `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** — вручную проверяет наличие обновлений
  - **`Run Diagnostics`** — ищет распространённые причины, из-за которых zapret может не запускаться или не работать.  
  В финале диагностики можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного сбоя
  - **`Run Tests`** — запускает проверку стратегий:
    - `Standard tests` — тестирует сайты из `utils/targets.txt`
    - `DPI checkers` — проверяет DPI у разных провайдеров, включая Cloudflare, Amazon и другие


## ☑️Частые вопросы и решения

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe. Его можно заметить на панели задач.  
Если процесс не появился, обратитесь к [#522](https://github.com/portalchemistagitate/zapret-discord-youtube/issues/522)

### Подходящей стратегии не нашлось
- Откройте командную строку с правами администратора
- Выполните в консоли команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если сохранённый hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого блокнота
  - В открывшейся папке найдите файл `hosts` и откройте его текстовым редактором, запущенным от имени администратора
  - Вставьте скопированное в конец файла `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните изменения и снова проверьте подключение. Если результата нет, убедитесь, что файл действительно был сохранён.

#### Результат не гарантируется. Если способ не помог, установите [Desktop-версию Telegram](https://github.com/telegramdesktop/tdesktop/releases) и подключите [локальный прокси](https://github.com/portalchemistagitate/tg-ws-proxy) либо любой публичный прокси.

### Обход не запускается или раньше работал, а теперь нет

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Вариант, который некоторое время обходил блокировку, может перестать работать после его обнаружения.
> В репозитории собрано много стратегий. Если ни одна не даёт результата, создайте собственную на основе одной из имеющихся, изменив её параметры.
> Описание параметров стратегий доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Откройте `service.bat` -> `Run Diagnostics` и убедитесь, что там нет ошибок

- Проверьте, внесён ли адрес нужного ресурса в списки доменов или IP

- Поочерёдно протестируйте другие варианты (**`ALT`**, **`FAKE`** и прочие)

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация есть в [#765](https://github.com/portalchemistagitate/zapret-discord-youtube/issues/765)

### Как выполнить полное обновление или переустановку?
- Сохраните добавленные вами ресурсы и другие нужные данные
- Перезагрузите устройство
- Откройте `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; если будут ошибки, исправьте их, а в конце подтвердите действие клавишей Y
- Удалите старую папку zapret
- Возьмите свежую версию [со страницы релизов](https://github.com/portalchemistagitate/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите правой кнопкой мыши на архив, откройте свойства и, если внизу справа есть флажок разблокировки, установите его, затем нажмите применить и ОК
- Распакуйте архив в новую папку в корне диска; путь не должен содержать пробелы и специальные символы
- Запускайте разные скрипты `general` и проверяйте доступ к нужным ресурсам. Если ресурс не открывается, закройте программу через значок замка на панели задач и попробуйте следующую стратегию
- После обнаружения рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service` -> выберите нужную стратегию

### Игра или приложение перестало работать при включённом zapret

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией по адресу https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### На Windows 7 требуется цифровая подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` файлами с такими же именами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Определите имя службы командой в командной строке Windows. Открыть её можно через Win+R и `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите и удалите найденную службу следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, включён ли [Secure DNS](#%EF%B8%8Fнастройка-и-запуск)
- Отключите блокировщик рекламы: известно, что YouTube начал активно бороться с ними
- Проверьте все остальные стратегии, особенно если прежний вариант больше не работает
- Дополнительные сведения приведены в [#251](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS](#%EF%B8%8Fнастройка-и-запуск) настроен
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить именно её
- В `service.bat` выберите `Run Diagnostics`, затем выполните очистку кэша Discord
- Проверьте, заработало ли приложение после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, временно пользуйтесь ей
- Если Discord не работает и в браузере, снова протестируйте все стратегии. YouTube и Discord могут открываться на разных вариантах
- См. также [#252](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/portalchemistagitate/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Игры не подключаются

Игр существует много, поэтому проверить и исправить каждую из них невозможно.

Начните с универсального варианта:
- через `service.bat` обновите ipset и активируйте `Game Filter`
- если это не поможет, дополнительно включите режим `ipset any`

Учитывайте, что `ipset any` может нарушить открытие большого количества сайтов. Не оставляйте этот режим включённым постоянно. Вместо этого определите все IP-адреса, которые использует игра, и добавьте их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Моей проблемы нет в списке

- Оформите обращение [здесь](https://github.com/portalchemistagitate/zapret-discord-youtube/issues)

## 🗒️Как добавить адреса других ресурсов

Дополнительные адреса для обхода можно указать в следующих файлах:
- **`list-general-user.txt`** — домены; поддомены будут учитываться автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить. Например, это полезно, когда IP-сеть присутствует в `ipset-all.txt`, но определённый домен из неё фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые следует исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
