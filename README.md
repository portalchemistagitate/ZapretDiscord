Если вы уверенно умеете настраивать исключения, предпочтительнее добавить папку в исключения. Если вы не до конца понимаете последствия настроек, рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Активируйте безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика, отличный от "Поставщик по умолчанию"
    * В Firefox откройте настройку "DNS через HTTPS", выберите режим "Персональный", затем пункт "Выбрать провайдера/поставщика" и вручную укажите URL. Например, можно задать `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * В Windows 11 Secure DNS можно включить непосредственно в параметрах операционной системы — [инструкция доступна здесь](https://remontka.pro/dns-over-https-windows-11/). Для пользователей Windows 11 этот вариант рекомендуется
    * На роутерах Keenetic включите параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать некорректно или не настроиться

2. Загрузите zip/rar-архив со [страницы последнего релиза](https://github.com/portalchemistagitate/zapret-discord-youtube/releases/latest)

3. Откройте свойства скачанного архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот пункт можно не выполнять

4. Извлеките файлы в каталог, путь к которому не содержит кириллицу и специальные символы

5. Запустите нужный скрипт
    * Для поиска работающей стратегии: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Для добавления стратегии в автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — запуск стратегии напрямую

  Ручной запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты — ALT, FAKE и другие, пока не найдёте подходящий для себя**

- [**`service.bat`**](./service.bat) — установка автозапуска и дополнительные операции:
  - <ins>**`Install Service`** — добавляет выбранную стратегию в автозапуск служб (services.msc)</ins>
  - **`Remove Services`** — удаляет стратегию и WinDivert из списка служб
  - **`Check Status`** — показывает состояние обхода и служб, включая автоматически запускаемую стратегию и WinDivert
  - **`Game Filter`** — включает или отключает режим обхода для игр и прочих сервисов, использующих UDP и TCP на портах выше 1023.  
  **После изменения этого параметра стратегию нужно перезапустить.**  
  Текущее состояние отображается в скобках: включено или выключено.
  - **`IPSet Filter`** — меняет режим обработки сервисов, перечисленных в `ipset-all.txt`.  
  Опция полезна при диагностике ресурса, который открывается без zapret, но перестаёт работать с ним.  
  В скобках отображается текущее состояние:
    - `none` — ни один IP не проходит проверку
    - `loaded` — проверяются IP, входящие в список
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включает или отключает автоматический поиск обновлений
  - **`Replace active fakes`** — заменяет используемый фейк на другой файл из каталога `bin`
  - **`Update IPSet List`** — загружает актуальную версию `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновляет hosts <ins>**для восстановления веб-версии Telegram и подключения к голосовым чатам Discord**</ins>
  - **`Check for Updates`** — вручную проверяет наличие обновлений
  - **`Run Diagnostics`** — ищет распространённые причины неисправности zapret.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда помогает после внезапного прекращения работы клиента
  - **`Run Tests`** — запускает проверку стратегий:
    - `Standard tests` — тестирует сайты из `utils/targets.txt`
    - `DPI checkers` — проверяет DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска `general*` ничего не появляется

- При запуске стратегии отдельным bat-файлом, а не через service, должен запуститься winws.exe. Его процесс можно увидеть на панели задач.  
Если этого не произошло, обратитесь к [#522](https://github.com/portalchemistagitate/zapret-discord-youtube/issues/522)

### Ни одна стратегия не работает
- Откройте командную строку с правами администратора
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезапустите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота
  - В открывшейся папке найдите файл `hosts` и откройте его текстовым редактором от имени администратора
  - Вставьте скопированное в конец файла `hosts` или замените ранее добавленные аналогичные строки
  - Сохраните файл и снова проверьте соединение. Если результата нет, убедитесь, что изменения действительно сохранились.

#### Работа веб-версии не гарантируется. Если предложенные действия не помогли, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/portalchemistagitate/tg-ws-proxy) либо с любым публичным прокси.

### Обход не запускается или перестал помогать

> [!IMPORTANT]
> **Стратегии не обязательно работают постоянно.**
> Вначале выбранная стратегия может справляться с задачей, но позже перестать работать после её обнаружения.
> В этом репозитории есть много вариантов обхода. Если ни один не дал результата, создайте собственную стратегию на основе одной из имеющихся и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- В `service.bat` откройте `Run Diagnostics` и проверьте, нет ли ошибок

- Проверьте, присутствует ли адрес нужного ресурса в списке доменов или IP-адресов

- Переключитесь на другие стратегии, включая **`ALT`**, **`FAKE`** и остальные варианты

- Выполните полную переустановку по инструкции ниже

- Дополнительные сведения есть в [#765](https://github.com/portalchemistagitate/zapret-discord-youtube/issues/765)

### Как полностью обновить или переустановить проект?
- Сохраните ресурсы и данные, которые добавлялись вами вручную
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Запустите `service.bat` -> `Run Diagnostics`; если найдены ошибки, исправьте их и в конце выберите Y
- Удалите каталог с zapret
- Загрузите свежую версию [со страницы релизов](https://github.com/portalchemistagitate/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`)
- Нажмите ПКМ по архиву, откройте свойства и, если в нижней части окна есть флажок разблокировки, установите его, затем выберите «Применить» и «ОК»
- Распакуйте архив в новую папку в корне диска, не используя пробелы и специальные символы
- Попробуйте разные скрипты `general`, то есть стратегии. Проверяйте доступность интернет-ресурсов: если они не открываются, закройте программу через значок замка на панели задач и запустите другую стратегию
- После выбора рабочего варианта добавьте его в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия

### Игра или приложение не работает при включённом zapret

- Убедитесь, что в `service.bat` параметр `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе фильтрация может затронуть ресурсы, которые вы не планировали обходить.

### Античит обнаруживает WinDivert

- Ознакомьтесь с инструкцией по адресу https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- В каталоге [`bin`](./bin) замените `WinDivert.dll` и `WinDivert64.sys` одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё остаётся среди служб

1. Определите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив полученное имя в следующие команды:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Отключите блокировщик рекламы: известно, что YouTube начал активно бороться с такими расширениями.
- Если прежний вариант перестал работать, последовательно проверьте остальные стратегии.
- См. также [#251](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions/251)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что настроен [Secure DNS](#%EF%B8%8Fиспользование)
- Сначала желательно определить стратегию, с которой открывается сайт YouTube, и запустить именно её
- В `service.bat` выберите `Run Diagnostics`, затем выполните очистку кэша Discord
- Проверьте, запустился ли Discord после очистки кэша
- Откройте Discord в браузере: https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не открывается и в браузере, снова проверьте все стратегии. Возможна ситуация, когда YouTube доступен с одной стратегией, а Discord — нет.
- См. также [#252](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions/252)

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/portalchemistagitate/tg-ws-proxy)
- Либо подключите бесплатный MTProto-прокси из интернета

### Игры не работают

Игр много, поэтому проверить и исправить каждую отдельно невозможно.

В качестве наиболее общего варианта попробуйте следующее:
- через `service.bat` обновите ipset и включите `Game Filter`
- если это не помогло, дополнительно активируйте `ipset any`

Учитывайте, что режим `ipset any` способен нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Вместо этого выясните все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/portalchemistagitate/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Проблемы нет в списке

- Создайте обращение [здесь](https://github.com/portalchemistagitate/zapret-discord-youtube/issues)

## 🗒️Добавление адресов прочих ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически
- **`list-exclude-user.txt`** — домены, которые нужно исключить. Например, если IP-сеть есть в `ipset-all.txt`, но определённый домен из неё фильтровать не требуется
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — IP-адреса и подсети, которые нужно исключить
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`
